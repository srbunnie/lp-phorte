# Live — A organização do tempo numa Perspectiva Pikleriana

Páginas estáticas da campanha:

- `index.html`: página principal com inscrição.
- `obrigado.html`: confirmação após o envio.
- `assets/`: recursos aprovados organizados para a campanha.

## Decisões

- Cor de campanha aplicada: `#c4d4c0`, com roxo Phorte para destaque e CTA.
- O formulário usa validação nativa e redireciona para `obrigado.html` como placeholder local do fluxo Elementor.
- No Elementor, substituir o formulário estático pelo widget nativo e configurar o redirect para a URL pública da página de obrigado.
- Não houve commit, push ou publicação.
