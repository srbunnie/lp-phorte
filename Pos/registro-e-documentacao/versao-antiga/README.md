# Cópia da versão anterior

Esta pasta contém a implementação inicial anterior ao redesign de alta conversão. Ela foi reconstruída a partir da estrutura e dos materiais da primeira versão do projeto, que não estava registrada como um commit separado no Git.

O backup inclui a landing page principal, a página de agradecimento, os assets locais e os arquivos de referência necessários para abrir a versão antiga.

A versão atual continua na raiz do projeto e não foi substituída.
