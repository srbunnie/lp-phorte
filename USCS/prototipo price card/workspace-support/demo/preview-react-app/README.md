# Preview React App

Projeto React minimo para visualizar e testar o componente `PriceCardUscs`.

## Rodar

```powershell
cd "C:\Users\Marcelo.vignola\Desktop\Git Projects\Daily\Componente Price Card USCS\workspace-support\demo\preview-react-app"
npm install
npm run dev
```

Depois abra a URL mostrada pelo Vite no navegador.

## O que este app faz

- renderiza o `PriceCardUscs`
- permite alternar entre `default`, `expanded` e `ead`
- usa os mocks locais do componente
- carrega Tailwind via CDN para manter o setup leve
