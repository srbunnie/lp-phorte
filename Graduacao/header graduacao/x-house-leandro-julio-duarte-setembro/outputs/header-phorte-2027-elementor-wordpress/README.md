# Header Phorte 2027 — WordPress / Elementor

O arquivo `header-phorte-2027-elementor.html` contém o trecho completo para um widget HTML do Elementor. Fontes e SVGs estão incorporados no snippet. A pasta `assets` reúne os arquivos de mídia e as fontes originais.

## Instalação

1. Envie os seis arquivos `.webp` de `assets` para a biblioteca de mídia do WordPress, mantendo os nomes. O snippet espera os arquivos em `https://faculdadephorte.edu.br/wp-content/uploads/2026/10/`.
2. Se o WordPress salvar em outro diretório mensal, ajuste a URL base das imagens no snippet antes de colá-lo.
3. No Elementor, use um widget HTML dentro de um contêiner de largura total e cole o conteúdo inteiro do arquivo HTML.
